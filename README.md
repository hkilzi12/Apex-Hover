# Apex Hover
A fictional hoverboard e-commerce website built as a hands-on learning project to practice HTML, CSS, and JavaScript fundamentals.

## About the Project
Apex Hover is a multi-page static website for a fictional levitating hoverboard company. The project was built from scratch as a structured way to learn front-end web development, with each new page and feature introducing new concepts.

## Pages
* **Home** — Company overview with hero sections, an "Our Story" and "How It Works" layout, and a global header/footer
* **Shop** — Product grid showcasing all 6 hoverboard models
* **Sale** — Highlights discounted models (Phantom V1 and UrbanDrift V1)
* **Product Pages** — Individual pages for each hoverboard with image, pricing, an add-to-cart button, and collapsible info/shipping dropdowns
* **FAQ** — Frequently asked questions using collapsible dropdowns
* **Support** — Contact and support information
* **Cart** — In progress; currently a placeholder while JavaScript cart functionality is being learned

## Skills Practiced
### HTML
* Semantic elements
* Forms 
* Anchor tags, image tags, and alt attributes
* `<details>` and `<summary>` for native collapsible dropdowns
* Linking external CSS files and Google Fonts
### CSS
* Flexbox and CSS Grid layouts
* Responsive design with media queries across multiple breakpoints
* Box model, position: sticky, object-fit, pseudo-classes, and transitions
* calc(), minmax(), CSS custom properties, and #region comments for organization
### General
* File and folder structure for a multi-page project
* #region and #endregion comments for code organization in VS Code
* Linking shared global stylesheets across pages
* Identifying and fixing issues with specificity, inheritance, and cascade order
